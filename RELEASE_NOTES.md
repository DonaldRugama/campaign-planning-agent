# v1.4 — Campaign Planning Agents
Three role-based agents share a local language model, retrieve supplied documents, validate selections and export a campaign report, calendar and trace. v1.4 prevents repeated captions, ties planning questions to the brief, simplifies evidence selection and adds stage progress to Gradio.

Start with practice mode, which needs only Python. AI mode installs the listed dependencies and downloads public models; it requires no paid API key. Use the included notebook for Colab or the README terminal commands. CPU generation can be slow. Gradio share links require an active runtime.

Validated with 17 core tests and user-run Colab and Gradio AI examples. Remaining model-selection failures are labeled Python fallbacks. The demo does not publish campaigns or spend money. See VALIDATION.md and examples/.
